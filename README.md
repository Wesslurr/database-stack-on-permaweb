# Database Stack on Permaweb

> **Status: Architectural Reset in Progress**

A new architecture is currently being prepared from the ground up for the latest **Permaweb (AO & HyperBEAM)** ecosystem.

During the initial iterations of this repository, too many layers were over-engineered—introducing custom protocols and unnecessary complexity where native AO processes and HyperBEAM devices already provide a stronger foundation. Recognizing this early, as the builder of this repository, I am resetting the codebase to rebuild a cleaner, leaner, and better-prepared shared-state database concept directly on this same branch (`beta`).

Previous iterations remain preserved in the commit history for reference while the new foundation is underway.
